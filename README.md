# Pigeon

Микросервис для отправки уведомлений через различные каналы связи

## Возможности

- **Email** — отправка через Sendmail
- **SMS** — (планируется)
- **Telegram** — (планируется)

## Требования

- Node.js >= 24.14.0
- Sendmail (доступен по пути `/usr/local/bin/sendmail`)
## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```
